# Hyvä recipes

Complete test builds for Magento sites running the Hyvä theme. Every recipe here follows `../_platform-context.md`: vanilla JS, WeakSet re-apply for anything Alpine renders, and custom CSS instead of Tailwind utilities.

The shared recipes in `../../shared/recipes/` also work on Hyvä. Tell the LLM it is a Hyvä site so it applies the Alpine rules.
