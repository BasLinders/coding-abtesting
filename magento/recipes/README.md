# Magento (Luma) recipes

Complete test builds for Magento 2 sites with the Luma frontend. Every recipe here follows `../_platform-context.md`: vanilla JS for the DOM, Magento JS modules only for data, and the WeakSet re-apply pattern in the checkout.

The shared recipes in `../../shared/recipes/` also work on Luma.

| Recipe | Status |
|---|---|
| `checkout-totals-block`: subtotal excl. VAT / total incl. VAT above the place-order button | ready |
| `plp-filter-pill-slider`: scrollable category pills above the product grid | ready |
| `free-shipping-bar`: progress bar to the free-shipping threshold, fed by customer-data | to do (pilot) |
| `checkout-trust-messaging`: reassurance messages next to payment methods | to do |
