# Shopify recipes

Complete test builds for Shopify themes. Every recipe here follows `../_platform-context.md`: vanilla JS, Cart AJAX API for data, and the WeakSet re-apply pattern for re-rendered sections.

The shared recipes in `../../shared/recipes/` also work on Shopify.
