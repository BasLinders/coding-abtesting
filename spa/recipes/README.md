# SPA recipes

Complete test builds for single-page applications (React/Next.js, Vue/Nuxt, Angular, ...). Every recipe here follows `../_platform-context.md`: robust selectors instead of hashed classes, the WeakSet re-apply pattern, and route-scoped setup and cleanup.
